# Saif Ur Rehman: Portfolio

Static site (HTML, CSS, Bootstrap 5, vanilla JS). Open `index.html` to run it locally (internet needed for CDN fonts/icons).

## Customize
- Replace `assets/images/profile.jpg` (4:5 portrait) and the four files in `assets/images/projects/` (16:10 screenshots), keeping the file names.

- Search `index.html` for `EDIT` and `[` to find placeholders: availability, LinkedIn, GitHub, timeline entries.
- To show Live demo / GitHub buttons, add real `<a>` links inside the matching `<dialog>`.
- Colors and spacing: CSS variables at the top of `style.css`.



## Deploy
Upload the folder contents to cPanel `public_html`, Netlify, Vercel or GitHub Pages.
